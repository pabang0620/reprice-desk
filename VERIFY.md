# VERIFY: what still has to be checked against the real sandbox

On 2026-11-12 the sandbox checks V1 (a, b), V2, V3, V5, V6, V7 and V17 were run against the PayPal sandbox (results below). The Anthropic API has not been called; V11 and V12 were attempted through the local Claude Code account (see their rows). The code paths exist and run on stand-ins; the items below are the ones only a real sandbox (or a real model) can confirm. Run them in this order. Run only after the owner approves; the sandbox buyer login conflicts with other jobs that use the same account.

Prerequisites (once):

1. A PayPal sandbox app (REST credentials) and two or three sandbox personal buyer accounts with a PayPal wallet balance. The sandbox business account must be able to take PayPal wallet payments. Card payments are off for this app (a dispute experiment got `PAYEE_NOT_ENABLED_FOR_CARD_PROCESSING`).
2. `.env`: `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `SANDBOX_BUYER_EMAIL`, `SANDBOX_BUYER_PASSWORD`, `BUNDLES_FILE=./data/bundles.json`.
3. `npm i -D playwright && npx playwright install chromium` (the buyer approver imports it; it is not an app dependency).

Every result goes into `docs/sandbox-checks.md` (the script writes request/response evidence; add your notes). If a check fails, use the fallback in the same row.
